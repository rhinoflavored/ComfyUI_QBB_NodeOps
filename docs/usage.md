# QBB NodeOps 使用指南

## 启动与排错

后端修改后重启 ComfyUI，前端修改后刷新网页。未找到入口时检查终端导入错误，确认 Python 版本和 `Send2Trash` 已安装到正确环境。Git 操作需要 `git --version` 在启动 ComfyUI 的环境中可用；GitPython 不能替代系统 Git。

部分加载判断来自捕获的 stdout/stderr、logging 和错误信号，无法替代实际工作流测试。日志和依赖清单可用于排查，但依赖清单不是完整环境备份。

## 资源与插件

清理前核对名称、路径和常用工作流。引用记录只说明提交时识别到了资源，不说明执行成功或覆盖全部动态加载。复制、解压可能改变文件时间。回收站未清空前仍占磁盘空间。

Git 更新采用快进方式，不自动解决冲突；更新后重启验证。市场分类与标签可能不完整，仓库信息受缓存和限流影响。下载不代表依赖齐全或插件能够加载。

## 记录与恢复

当前固定范围为核心、插件、Python 包状态和 `extra_model_paths.yaml`，不包含模型、工作流、`user`、输入输出和外部资源。不打包或替换整个解释器，也不包含 GPU 驱动。

保存先预览，检查排除项、缺口和空间。扫描后预览有效期为 30 分钟；保存选项或源文件变化后重新预览。捕获会核验文件，但不是原子快照，保存期间应保持环境静止。对象按哈希复用，改变的大文件可能需要保存整份新内容。

组件 ZIP 保存文件和校验索引。Python 包按可读取的已安装文件与元数据保存，缺失安装清单、共享文件和路径冲突会形成缺口。有完整有效归档时，未知来源本身不一定阻止恢复；备份存在不能证明整个环境可恢复。

默认宽松对比仅核对名称，同名插件、包和配置保持现状，不检查内部内容和版本。严格对比核对版本、来源和文件。缺少历史证据或读取失败会显示未知，不能当作一致。

恢复前核对删除、替换项并准备材料，执行沿用已确认计划。恢复窗口打开后手动关闭原 ComfyUI，等窗口提示完成后再手动启动。离线期间浏览器无法读取实时进度，请查看独立窗口；不要提前启动第二份 ComfyUI。

结果会说明操作是否完成及是否重新扫描。当前流程可能不重新扫描，所以“计划已执行”不能代替最终内容核验。需要时重新严格对比并测试工作流。失败回退不代表达到目标版本；回退不完整时保留任务目录和日志。

JSON 导出仅包含清单，文件包包含引用对象；导入不会自动安装或恢复。旧记录缺少的文件不会补造。切换存储位置不会搬动旧记录。记录和对象库可能包含私人配置，只导入、恢复可信内容。

## 实例创建与搬家

创建实例从官方仓库下载 ComfyUI，分别存放程序和 Python 环境。Windows 使用外层 `run_comfyui.bat`，程序在 `ComfyUI/`，环境在 `python_env/`。不会自动复制现有插件、模型或配置。

版本选择依据安装包和本机硬件检测；无法确认 NVIDIA 环境时可能只提供 CPU。CUDA 指 PyTorch 构建，不安装显卡驱动。安装检查不保证第三方插件兼容。保持网络和 ComfyUI 后台运行，关闭面板不等于取消任务。

搬家向已有目标复制选定插件，用目标 Python 安装、检查依赖。不覆盖同名插件，不搬核心和模型；失败可能留下部分依赖。默认保留来源。如选择回收来源，先用另一端口启动目标验证，再回原面板确认。确认前保持来源后台运行并暂停工作流，回收后再重启来源。

## 设置与本机数据

AI 分析需主动发起，不自动执行建议，可连接远程或本地兼容服务。通信测试可能产生费用，不保存表单。Key 在本机未加密存储，更换远程地址时需重新提供或明确清除旧密钥。

网络设置支持直连、代理和 GitHub 镜像，代理端口须匹配实际配置。连接测试仅验证测试地址；镜像不替代 Python、PyPI、PyTorch 或 AI 地址。

`qbb_nodeops_*.json`、数据库、`record-tasks/`、`restore-tasks/` 属于本机状态，不应提交到 GitHub。分享诊断信息前删除密钥、令牌和私人路径。

在仓库根目录执行：

```bash
python -B tests/run_local_archives_acceptance.py
node tests/test_snapshot_ui.cjs
node tests/test_compare_ui.cjs
node tests/test_state_plan_ui.cjs
```

验收使用临时实例，覆盖捕获、归档、对比与恢复逻辑。测试通过不证明真实联网安装、所有平台、GPU 和第三方工作流均可用。历史测试可能描述旧流程，以具体结果和当前代码为准。
